# SAM AI MEDIA FACTORY

Phase 1 content planning dashboard. Includes research briefs, script saving/export, production planning, publishing checklist and analytics placeholders.

## Run
`pip install -r requirements.txt`
`streamlit run app.py`

## Limitations
This does not yet generate videos, research live trends, connect accounts, auto-publish or collect live analytics. These require additional integrations and permissions. Cloud local storage may be temporary.
